# fragrance-discovery-platform
AI-powered fragrance recommendation platform. Analyzes user preferences and suggests matching perfumes from a comprehensive database using Groq AI and natural language processing. AI destekli parfüm öneri platformu. Kullanıcı tercihlerini analiz eder ve Groq AI ile doğal dil işleme kullanarak kapsamlı veritabanından eşleşen parfümleri önerir.
